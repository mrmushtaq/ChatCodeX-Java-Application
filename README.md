To execute your Java files in the "DSA Project" folder, open your IDE and import the "DSA Project" folder. 
Locate and open MainExeFile.java, which contains the main method. Ensure that MainExeFile.java properly 
calls methods from HelperFile.java. Build the project to resolve dependencies, then run MainExeFile.java 
to start the application and view the output in the console.
